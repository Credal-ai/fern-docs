## Overview

Human approval gives you a safety layer on top of any action. When enabled, the agent pauses before executing an action and presents the proposed inputs to a human for review — ensuring nothing runs without an explicit sign-off.

There are two ways to enable human approval, and they can be used together:

- **On a specific action in an agent** — enable it yourself when attaching an action to an agent
- **Organization-wide via admin controls** — admins can require approval for an entire action template or MCP server tool, ensuring consistent governance across your org

## Enabling human approval on an action

When you attach an action to an agent, scroll to the **Governance** section at the bottom of the action's settings. Toggle on **"Double-check: Require human approval before executing this action"** to enable it.

![Governance toggle in action settings](/docs/assets/actions/action-governance.png)

Once enabled, a small orange gavel icon will appear on the action in the agent's connector list, indicating governance is active.

![Action with governance icon](/docs/assets/actions/action-with-gov-icon.png)

## Organization-level enforcement

Admins can enforce human approval for all actions created from a given template, across the entire organization. This is configured in the [System Connectors](https://app.credal.ai/admin/system-connectors) admin panel — each template has an independent **Require Human Approval** toggle.

When enabled at the template level, every action of that type will require approval before executing, regardless of how individual agents have configured it. This is the recommended approach for sensitive categories of action, such as:

- Actions that write to production systems or databases
- Actions that communicate externally (emails, Slack messages, tickets)
- Actions that involve financial or compliance-sensitive operations

See [Action Templates](/user-guide/platform/governed-actions/action-templates) for more on managing templates.

## Human approval for MCP server tools

For imported MCP servers, admins can enforce human approval at the individual tool level. Navigate to the MCP server's settings and use the **Enforce Human Approval** control next to any tool you want to gate.

![MCP tool controls](/docs/assets/actions/mcp-tool-controls.png)

This ensures that even tools from third-party servers cannot run without a human review step. See [Setting up Controls](/user-guide/platform/managing-mcp-servers/setting-up-controls) for full details.

## The approval experience

When an agent triggers an action that requires approval, it pauses and waits. You'll see a **pending approvals** notification in the chat interface — click the hammer icon to open the approvals panel.

The approvals panel shows:

- **Who requested the action** and when
- **The justification** the agent provided
- **The exact inputs** the agent plans to send — so you can verify them before anything runs

![Pending action approvals modal](/docs/assets/actions/governance-modal.png)

Review the inputs, and click **Approve** to proceed. If the inputs don't look right, you can reject the action and ask the agent to try again with different instructions.
